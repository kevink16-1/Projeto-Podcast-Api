# Projeto-Podcast-Api
O Projeto Podcast API é uma aplicação back-end desenvolvida para gerenciar e distribuir conteúdos de áudio. A ferramenta fornece endpoints estruturados para o cadastro completo de programas, episódios e criadores. Ideal para integração com front-ends e aplicativos mobile, a API garante excelente desempenho, código limpo e arquitetura escalável
